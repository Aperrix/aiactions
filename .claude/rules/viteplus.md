# Vite+ toolchain rules

All tasks go through `vp` (Vite+), which wraps Vite, Vitest, tsdown, Oxlint, Oxfmt, and the package manager. Node `>=22.12.0`, Bun 1.3.13.

## Common commands

- `vp install` — install dependencies (after pulling or dependency changes)
- `vp run ready` — full verification (`check` + `-r test` + `-r build`)
- `vp run -r test` / `vp run -r build` — recursive across workspaces
- `vp check` — type check + lint (type-aware enabled)
- `vp test [pattern]` — run tests in the current package (Vitest-compatible)
- `vp pack [--watch]` — build a library package
- `vp dev` / `vp build` / `vp preview` — Vite built-ins
- `vp lint` / `vp fmt` — Oxlint / Oxfmt
- `vp add <pkg>` / `vp remove <pkg>` / `vp update` / `vp outdated` / `vp dlx <bin>` — package manager ops
- `vp upgrade` — update `vp` itself (and its wrapped tools)

Run `vp help` or `vp <command> --help` to discover options.

## Non-obvious rules

- **Never call `bun`/`npm`/`pnpm`/`yarn` directly.** Use `vp add`/`remove`/`install`/`dlx` — Vite+ wraps the package manager declared in `packageManager`.
- **Never install `vitest`/`oxlint`/`oxfmt`/`tsdown` as dependencies.** They are bundled into `vite-plus` and updated via `vp upgrade`. Installing them directly is an anti-pattern.
- **`vp <cmd>` ≠ `vp run <cmd>`.** Built-ins (`vp dev`, `vp build`, `vp test`, `vp check`, `vp lint`, `vp fmt`) always invoke the built-in tool, **not** a `package.json` script of the same name. To run a custom script, always use `vp run <script>`.
- **Imports come from `vite-plus`, never from `vite`/`vitest`.** Config files: `import { defineConfig } from "vite-plus"`. Tests: `import { expect, test, vi } from "vite-plus/test"`.
- **Type-aware lint works out of the box** — do not install `oxlint-tsgolint`; `vp lint` (with `typeAware: true` in config) handles it.
- **Do not hand-edit `exports` in `package.json`** for packages built with `pack.exports: true` — it is regenerated by `vp pack`.

## CI hint

Prefer `voidzero-dev/setup-vp@v1` over separate Node + package-manager + cache setup steps.
